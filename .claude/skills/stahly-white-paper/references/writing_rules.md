# Writing rules

## Easy to follow
- **Bottom line first**: decision or required action in the first 2 sentences; support follows.
- **Scannable**: informative, keyword-first headings ("Calibrate the scanner", not "Background"); paragraphs ≤ 5 lines; lists for parallel items; tables for comparisons.
- **Plain language**: active voice, "you", sentences ≤ ~25 words, common words, each term defined once and used consistently.
- **One type per section**: rationale ("why") in its own short section, linked from the steps.
- **Lean**: every element helps the reader act or decide. Figures sit beside the text they explain; anecdotes and images earn their place by teaching.
- **Examples by expertise**: worked example for every non-trivial task for novices; compact reference tables for experts.

## Followed accurately
- **Procedures**: numbered steps, one action each, imperative verb first; condition before action ("If the light is red, stop"); expected result after key steps.
- **Notes inform only**; every action lives in a numbered step.
- **Warnings** sit immediately before the hazardous step: signal word (DANGER/WARNING/CAUTION) + hazard + consequence + how to avoid. Reserve them for real risk so each one is noticed.
- **Checklists** for critical, skippable, or order-sensitive items: killer items only, ~5–9 per pause point, checkbox per item, order matching the physical workflow.
- **Place-keeping** for procedures > 10 steps: checkboxes and step numbers.
- **Credible why**: state the reason behind each non-obvious rule; readers comply with rules they believe.
- **Document control**: owner, version, date, review cycle, feedback channel.

## Delightful
- Conversational "you"/"we" voice; confident, plain.
- Fluency: simple words read as more credible and intelligent.
- Consistent, attractive brand layout (see build gate).
- Respect time: the reader finishes the task and leaves.
