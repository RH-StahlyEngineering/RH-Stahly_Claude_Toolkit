# Stahly survey field prep

Language for getting a Stahly survey job from signed contract to a crew in the field.

## Language

**To-field package**:
Everything a crew needs before leaving: control and base plan, targets, flight plans, 811 status, pickup list and exhibit, boundary search notes, and the field card. Done when the field card is published and every open item is closed or assigned.
_Avoid_: field prep, field packet

**Baseline sweep**:
The fact-finding pass a skill makes over the project folder, proposal, email, prior Stahly work and public data before it asks the surveyor anything.
_Avoid_: research phase, discovery

**Fact**:
Something a source states, recorded with that source. Facts are looked up, never asked for.

**Decision**:
A choice only the surveyor makes (grid, base, targets, scope reading). Decisions are asked, never assumed.

**Control index**:
A searchable map of where prior Stahly control and monument records exist, by approximate location.
_Avoid_: control database, control library

**Locator**:
An approximate location stored in the control index to find a record by radius. Never a survey value; survey values are read from the source file.
_Avoid_: coordinate (for index entries)

**Field card**:
The crew's one-stop reference for a job: a PDF, a phone page, and data collector points generated from one point list.
